# Party Game（手機當搖桿的派對遊戲大廳）

電腦／電視開主畫面，朋友用手機掃 QR Code 加入，先選角色與衣服顏色，進**遊戲大廳**（左欄選遊戲、右欄是已加入的玩家），主持人選好遊戲按「開始」。

目前的遊戲：
- 🏃 **跑步**：用手機**左右兩顆按鈕交替連按**讓自己的角色往終點跑。
- ⚽ **足球**（測試中）：俯視球場，用虛擬搖桿跑位推球；紅藍分隊（最多 5v5）、進球計分、3 分鐘比賽、平手金球加時、結算。手機左邊是搖桿，右邊是**頭槌**區域與**衝刺**按鈕：頭槌 = 按住蓄力，並像搖桿一樣**往想打的方向滑動**，放開就打出去（球在角色附近時，頭會直接衝向球，球照你滑的方向飛；滑得越遠、蓄得越久，球越快；滑的方向接近對方球門時會自動修正成正對球門）；衝刺有冷卻。道具之後再做，規劃見 [`docs/soccer-plan.md`](docs/soccer-plan.md)。
- 🌀 **陀螺大戰**（開發中，S3）：個人混戰，操控圓盤（中間是角色大頭）互撞、把別人撞出平台。平台是**碗型**（中間下凹：往中心衝會加速、往外圍衝會減速，比較不會自己衝出去）。第 1 回合計時賽（被撞出去 5 秒後復活，比誰撞得多）；第 2 回合淘汰賽（不復活、平台縮小，剩最後 3 位）。手機**傾斜**操控（陀螺儀），或用搖桿備案；有**衝撞**鈕（冷卻 2 秒，衝撞中撞到人對方飛更遠）；規劃見 [`docs/spinner-plan.md`](docs/spinner-plan.md)。

- **每組最多 5 人**，人數不能整除時平均分組（10 人 → 5+5、11 人 → 4+4+3），全部組別跑完後依「抵達時間」結算總成績。
- 角色可以重複，**衣服顏色同一場不能重複**（共 12 色，所以最多 12 人能上場）。
- 後端只轉送訊息；**遊戲邏輯都在主畫面（host）端**：大廳在 `public/host.js`，每個遊戲一個檔案放在 `public/games/`。

```
├── package.json
└── public/
    ├── host.html / host.js            # 主畫面：遊戲大廳（玩家、選角色與顏色、選遊戲、階段、與手機溝通），提供 Hub 給各遊戲用
    ├── games/
    │   ├── race.js                    # 「跑步」遊戲：規則、分組、名次、Phaser 跑道場景
    │   ├── soccer.js                  # 「足球」遊戲：球場、物理、搖桿輸入
    │   └── spinner.js                 # 「陀螺大戰」遊戲（開發中）：平台、圓盤物理、兩回合
    ├── char-render.js                 # 各遊戲共用：角色的大頭貼圖與跑步身體動畫（程式即時畫）
    ├── controller.html / controller.js # 手機控制器
    ├── characters.json                # 角色清單（4 個，每個有 art 大圖與 head 頭圖）與可選的衣服顏色（12 色）

    └── img/                           # 角色圖：NN.jpg（或 .png）是選角時的大圖，NN_head.png 是頭（透明背景 PNG；沒填的角色用預設臉）
```

## 啟動

需要 Node.js 18 以上。

```bash
npm install
npm start
```

終端機會印出主畫面網址，例如 `http://192.168.1.23:3000/host.html`。

### 假玩家測試（不用真的手機）
```bash
npm start                              # 另一個終端機：開伺服器、在瀏覽器開主畫面，記下房號
npm run fake -- <房號> 10              # 10 個假玩家加入，依遊戲自動玩（跑步連打；足球搖桿 + 頭槌 + 衝刺）
npm run fake -- <房號> 10 --chaos      # 混亂模式：隨機斷線，1～3 秒後用同一個身分重連
```

### 手機連線測試
1. 電腦與手機連**同一個 Wi-Fi**。
2. 電腦瀏覽器開終端機印出的網址（用區網 IP 那個），畫面會顯示房號與 QR Code。
3. 手機掃 QR Code → 輸入暱稱 → 加入 → 選角色 → 選衣服顏色。
4. 主畫面按「開始」（沒選好的人這場不會上場）。

常見問題：
- **手機打不開**：Windows 防火牆第一次會問 Node.js，請選「允許私人網路」。
- **QR Code 的 IP 不對**（電腦有多張網卡）：用 `$env:LAN_IP="192.168.x.x"; npm start` 手動指定。
- **Wake Lock、震動**：Wake Lock 只在 https 下有效（部署到 Render 就有）；iPhone 不支援震動。

## 新增 / 更換角色圖
1. 大圖 `xx.png`、頭 `xx_head.png`（透明背景）放進 `public/img/`。
2. 在 `public/characters.json` 的 `characters` 裡填上 `"art": "img/xx.png"`、`"head": "img/xx_head.png"`。
3. 選角畫面：下排小方格是 `head`，點選後上方顯示 `art`；比賽時 `head` 會接在跑步身體上。
4. 大圖檔案越大，手機載入越慢，建議壓到 1MB 以內。

## 遊戲流程

大廳（`lobby`）選遊戲 →（跑步）→ 結算後可「再來一場」或「回遊戲大廳」。

新增遊戲：
1. `public/host.js` 的 `GAME_LIST` 加一項（`enabled: false` 會顯示「即將推出」）。
2. 新增 `public/games/xxx.js`，結尾登記 `Hub.games.xxx = { start, stop, onInput, ... }`（介面說明在 `host.js` 最上方，範例是 `games/race.js`），並在 `host.html` 加上 `<script>`。
3. 大廳負責玩家、角色、顏色與廣播；遊戲只管自己的規則與畫面，自己的玩家狀態放在 `p.xxx`（跑步用 `p.race`）。

跑步的階段：`lobby → countdown → racing → heatResult →（下一組 countdown …）→ result`

1. 大廳：顯示房號、QR Code、已加入玩家，至少 1 人才能按「開始」。
2. 依加入順序平均分組（每組最多 5 人），每組先 3、2、1、GO 倒數（手機按鈕鎖住）。
3. **左右交替**按才會前進，每下前進 `STEP_DISTANCE`；**左右同時按會跌倒**（`FALL_MS` 內按鍵無效）；**連按同一邊會原地跳一下**、這下不前進，之後 `SLOW_MS` 內每步只前進 `SLOW_FACTOR`。所有人都到終點，該組才結束（讓最後一名也跑完）；只有第一名到後超過 60 秒還有人沒到，才會強制結束。離線的人不用等。
4. 顯示該組結果，按「開始下一組」。沒輪到的手機會顯示等待。
5. 最後一組完成後顯示總成績：先依抵達時間排序，沒跑完的排最後（依位置）。
6. 「再來一場」：重新分組、從第 1 組開始倒數。

細節：
- 遊戲開始後才加入的人，這場先等待，下一場才會被分組。
- 遊戲中斷線的人保留位置、標示離線，重整後用同一個 playerId 會接回來。
- 大廳中斷線的人會直接從名單移除。
- **host 重整頁面或斷線＝房間作廢**，需重新建立。

## 跑步的遊戲數值（`public/games/race.js` 最上方）

| 常數 | 意義 |
|---|---|
| `TRACK_LENGTH` | 跑道長度（現在 3000，每步 25 → 要按 120 下，一場大約 20 秒） |
| `STEP_DISTANCE` | 每按一下前進距離 |
| `PLAYERS_PER_HEAT` | 每組最多幾人（會平均分） |
| `FALL_MS` | 左右同時按 → 跌倒多久 |
| `SLOW_MS` / `SLOW_FACTOR` | 連按同一邊 → 變慢多久／變慢後每步的比例 |
| `COUNTDOWN_SECONDS` | 倒數秒數 |
| `FINISH_TIMEOUT_MS` | 第一名到後最多等多久（現在 60 秒，讓最後一名也能跑完；全部到終點就立刻結束） |
| `HEAT_MAX_MS` | 保險：單組最長時間 |

## 事件列表

| 事件 | 方向 | 內容 |
|---|---|---|
| `host:create` | host → server | 建立房間；callback 回傳 `{ room, controllerUrl }` |
| `player:join` | 手機 → server → host | `{ room, playerId, name }`（server 轉給 host 時為 `{ playerId, name }`）；手機有 callback `{ ok, error }` |
| `game:state` | host → 所有手機 | `{ phase, heat, totalHeats, taken }`（`taken` = 已被選走的顏色），phase 為 `lobby / countdown / racing / heatResult / result` |
| `tap` | 手機 → host | `{ side }`，side 為 `L / R / both`（server 補上 `playerId`） |
| `input` | 手機 → server → host | `{ mx, my, dash, neck }`，足球的持續輸入（搖桿方向 -1~1；衝刺、頭槌是否按住）；有東西按住時每 150ms 重送一次整組，server 補上 `playerId` 並限制範圍 |
| `player:pick` | 手機 → server → host | `{ charId, color }`；host 檢查顏色有沒有被選走，結果用 `player:status` 回 |
| `player:status` | host → 單一手機 | `{ playerId, status }`；status 含 `role / heat / picked / charName / color / finished / heatRank / overallRank / finishTime` |
| `player:left` | server → host | `{ playerId }`，玩家斷線 |
| `room:closed` | server → 手機 | host 離開，房間關閉 |

> `heatResult`（每組結果）是在你要求的四個階段之外多加的一個，用來在組與組之間停一下。

## 足球的規則與數值（`public/games/soccer.js` 最上方）

| 常數 | 意義 |
|---|---|
| `MAX_PLAYERS` | 最多上場人數（10 人 = 5v5），超過的人這場先等 |
| `MATCH_SECONDS` | 一場比賽幾秒（預設 180） |
| `OVERTIME_SECONDS` | 平手時金球加時最久幾秒；加時仍沒進球就算平手 |
| `COUNTDOWN_SECONDS` / `GOAL_PAUSE_MS` | 開球倒數秒數／進球後慶祝多久（慶祝與倒數時比賽時間暫停） |
| `MAX_SPEED` / `ACCEL` | 角色最高速度／加減速的靈敏度 |
| `CHARGE_SECONDS` / `CHARGE_MOVE` | 頭槌蓄滿要多久／蓄力時移動速度的比例 |
| `NECK_MIN` / `NECK_MAX` | 脖子最短／最長伸出的距離 |
| `GRAB_RANGE` | 球離角色多近（像素）時，頭會直接衝向球、球再照瞄準方向飛 |
| `AIM_ASSIST_DEG` | 瞄準輔助角度（滑的方向和球門方向差在這個角度內就自動修正；0 = 關閉） |
| `AIM_POWER` | 滑得越遠、不用蓄力也打得越用力的程度 |
| `KICK_MIN` / `KICK_MAX` | 頭槌把球打出去的速度（輕點／蓄滿） |
| `DASH_SPEED` / `DASH_SECONDS` / `DASH_COOLDOWN` | 衝刺速度、持續時間、冷卻 |
| `BALL_DRAG` / `WALL_BOUNCE` / `HIT_BOUNCE` | 球的滾動阻力／撞牆彈性／被角色撞時的彈性 |

規則：紅隊守左邊球門、攻右邊球門，藍隊相反；球整顆越過球門線才算進球。最後碰到球的是對方隊員則算**烏龍球**（得分給進攻隊，但不記個人進球）。

### 斷線與重連（足球）
- 手機斷線 / 沒訊號 / 切分頁：角色變成半透明的「幽靈」，不會動也不會擋路，球可以穿過去；手機用同一個身分重連（重新整理頁面或網路恢復會自動重連）就會回到原本的角色與隊伍。
- 搖桿或按鈕超過 0.6 秒沒收到更新，一律當作放開；蓄力中斷線會取消，不會突然撞出去。
- **整隊**的人都離線時，畫面上方會提示；`FORFEIT_GRACE_MS`（預設 15 秒）內沒人回來，該隊判棄權、另一隊獲勝；兩隊都沒人就自動回大廳。
- 伺服器會限制每個連線每秒最多送幾次輸入（`server.js` 的 `RATE_LIMIT`），避免有人（或壞掉的網頁）狂送訊息拖垮主畫面。
- **主畫面（host）重新整理或斷線 = 房間作廢**，這一點不變；開著主畫面的電腦不要休眠。

## 陀螺大戰的規則與數值（`public/games/spinner.js` 最上方）

| 常數 | 意義 |
|---|---|
| `ROUND1_SECONDS` / `RESPAWN_MS` | 第 1 回合長度／被撞出去多久後復活 |
| `SPAWN_PROTECT_MS` | 復活後的無敵時間（不會被撞、也不會撞人） |
| `KILL_CREDIT_MS` | 被誰撞最後一下、幾秒內掉下去，就算那個人的擊殺 |
| `FINALISTS` | 第 2 回合剩幾位就結束（參賽 3 人以下則打到剩 1 位） |
| `SHRINK_START_S` / `SHRINK_SECONDS` / `SHRINK_MIN_RATIO` | 第 2 回合開打幾秒後開始縮圈、縮多久、最小縮到幾倍 |
| `BOWL_G` | **碗的拉力**（在平台邊緣拉向中心的加速度）：要比 `ACCEL` 大，才不會自己衝出去 |
| `ACCEL` / `DAMP` / `MAX_SPEED` | 圓盤加速度／滑行阻力／自己操控的最高速度（手感主要調這幾個） |
| `HIT_BOOST` / `RESTITUTION` / `HARD_MAX_SPEED` | 撞擊力道加成／互撞彈性／被撞飛時的最高速度（越大越容易把人撞出去；擊殺數對 `HIT_BOOST` 非常敏感） |
| `RAM_SPEED` / `RAM_SECONDS` / `RAM_COOLDOWN` / `RAM_POWER` / `RAM_MAX_SPEED` | 衝撞：額外加速／持續時間／冷卻／衝撞中撞到人對方受到的力道倍率／衝撞中速度上限 |
| `PREPARE_MS` | 準備階段最久等多久 |
| `RESTITUTION` | 互撞的彈性（越大撞得越遠） |

規則：圓盤中心超出平台邊緣就掉下去；最後撞到你的人，3 秒內算他的擊殺，自己掉下去不算任何人擊殺。第 1 回合結束 10 秒後自動開始第 2 回合（主持人也可以按「開始第 2 回合」）。

### 陀螺大戰的體感操控（手機端，`public/controller.js` 的「陀螺大戰：陀螺儀」一節）
| 常數 | 意義 |
|---|---|
| `TILT_FULL_DEG` | 傾斜幾度算推到底（預設 25°，越小越靈敏） |
| `TILT_DEAD` | 死區（0~1），太小的傾斜當作沒動 |
| `GYRO_SMOOTH` | 平滑（越大越跟手、越小越穩） |

**注意：手機的陀螺儀只有在 https 網址才能用**（Render 的網址可以；區網 `http://192.168.x.x` 不行，會自動改用搖桿）。iPhone 會跳出「動作與方向」授權視窗，要選「允許」。

## 音效與配樂（`public/audio.js`）

只在**主畫面**播放，全部用 Web Audio 即時合成，不需要任何音檔。
- 瀏覽器規定要先點一下頁面才會出聲：主畫面右下角的 🔊 會閃一下提醒，點任何地方就會開始；🔊 可靜音、旁邊的滑桿調音量（也可按 `M` 靜音），設定會記在瀏覽器裡。
- 配樂：大廳／結算一首輕鬆的，跑步、足球、陀螺大戰各一首（`TRACKS` 裡用小節、音階度數、鼓點描述，想改曲子改那裡）。
- 音效：`Sfx.play('名稱')`，名稱有 join、beep、go、step、stumble、finish、kick、dash、whistle、goal、hit、ram、fall、respawn、roundEnd、win。
- 之後想換成自己的音檔：把 `Sfx.play` / `Sfx.music` 內部改成播放檔案即可，遊戲程式不用動。

## AI 玩家（`public/ai.js`）

大廳右欄的「＋ AI」「－ AI」可以加減 AI 玩家（只能在大廳加減，總人數最多 12）。AI 是在主畫面裡跑的假玩家，用和手機一樣的輸入格式呼叫遊戲的 `onInput()`，不需要真的手機：
- 跑步：左右交替點，偶爾手滑連按或同時按而跌倒。
- 足球：離球最近的追球、站到球後面對準球門頭槌，其他人站在球和自己球門之間防守。
- 陀螺大戰：自動按準備好；撞最容易掉出去的人、會衝撞；太靠邊就回中間。
每個 AI 的反應與準度（`skill`）略有不同。想調難度改 `ai.js` 裡的 `skill` 範圍與各 `*Tick` 的機率。

## 足球必殺技

每人每場一次。球在身邊（約 150 px 內）時，手機的「必殺技」鈕會閃，按下去：全場時間暫停、除了出招者和球以外變暗，出招者有 **1 秒**用左邊搖桿瞄準（沒推搖桿就預設對準**自己的**球門，要記得瞄準；方向離球門 40° 內會自動吸附成正對球門，所以很穩）。1 秒後球以 2400 px/s 的超快速度飛出去，**1 秒內穿過所有角色、不會被擋住**（還是會被場邊彈回、會進球），之後恢復一般球速。數值在 `soccer.js` 最上方的 `ULT_*` 常數。

AI 玩家的難度（簡單／普通／困難）在大廳「＋ AI」旁的下拉選單，預設簡單；AI 也會在球在身邊、離對方球門不遠時放必殺技（機率依難度）。

## 跑步的角色技能

每人每場**最多 3 次**（要等上一次效果結束才能再用），比賽中按手機上「跑道按鈕」上方的技能鈕發動。**每次有 33% 的機率失敗**（技能由角色決定，數值在 `race.js` 的 `SKILLS` 與 `BOAR_* / SING_* / GIANT_* / SLIDE_* / SKILL_USES / SKILL_FAIL` 常數）：

| 角色 | 技能 | 成功 | 失敗（33%） |
|---|---|---|---|
| 07 史瑞獸 | 🐗 騎山豬 | 3 秒內每步 ×1.8；不會跌倒、連按同一邊也不會被懲罰 | 摔下來：跌倒，2.4 秒按鍵無效 |

## 陀螺大戰的場中障礙

比賽中會隨機出現障礙（`spinner.js` 的 `OBS_*` 與各障礙常數）：開打約 5 秒後出現第一個，之後每 5~8 秒一個，同時最多 3 個（10 人以上 2 個）。每個障礙先**預告 1.5 秒**（閃爍輪廓、沒有效果）→ **生效 10 秒** → 淡出 1 秒後消失；縮圈吃到的會提早消失。主畫面右側的訊息欄會寫「⚡ 加速帶 出現了！」。

| 障礙 | 效果 | 第 1 回合 | 第 2 回合 |
|---|---|---|---|
| ⚡ 加速帶 | 壓到就往箭頭方向 +420 速度（每顆圓盤 0.6 秒最多一次） | ✓ | ✓ |
| 🧊 冰面 | 滑行阻力 ×0.2、自己操控的加速 ×0.5（很滑） | ✓ | ✓ |
| 🟤 泥地 | 滑行阻力 ×3（停得快、不容易被撞飛） | ✓ | ✓ |
| 🔴 彈跳柱 | 撞到強力彈開（彈性 1.3，輕的彈得更遠） | ✓ | ✓ |
| 🔄 轉盤 | 帶著圓盤繞圈（切線加速度，越靠邊越強，重的比較穩） | ✓ | ✓ |
| 🪵 旋轉棒 | 中間一根會轉的棒子，掃到就撞開 | | ✓ |
| 🕳 洞 | 圓盤中心進去就掉下去（算最後撞到的人的擊殺） | | ✓ |

AI：普通／困難會避開洞；簡單完全無視障礙。復活位置會避開洞、柱子和旋轉棒。測試用：`Hub.games.spinner._set({ addObstacle: { type, x, y, angle, dir, activeS } })`、`noSpawn`、`clearObstacles`。

## 猜猜他是誰（搶答，`public/games/quiz.js`）

類似 Kahoot：主畫面顯示一張照片，**要猜的那個人被黑色剪影蓋住（其他人正常顯示）**，手機上有 A B C D 四個大按鈕。全部答完或時間到（預設 15 秒）→ 剪影淡出、揭曉答案與各選項人數 → 排行榜 → 下一題 → 最終排名。

- 計分：答對 500 分 + 剩餘時間比例 × 500（越快越高，最高 1000）；連續答對第 2 題起每題 +100，最多 +300。答錯或沒答 0 分。每題只算第一次作答，不能改答案。
- AI 玩家也能玩（簡單 35%／普通 65%／困難 92% 答對，作答時間不同）。
- **題庫**在 `public/quiz/questions.json`：每題 `image`（原圖）、`mask`（黑色剪影 PNG，透明背景、只有要猜的人是黑的）、`name`（正確答案）。**四個選項由遊戲自動產生**：正確答案 + 3 個干擾（從檔案裡的 `decoys` 名單和其他題的答案隨機挑，不重複），正確答案的位置每次隨機。想自己指定某題的選項，可以改用 `options`（四個文字）加 `answer`（0=A 1=B 2=C 3=D）。
- **新增題目**：把照片給我並標記要猜的人，我用 SAM（圖片分割）切出輪廓、做成剪影，檢查預覽後放進 `public/quiz/` 並加進題庫。

## 累計積分與結算排名（`public/scoring.js`）

每個遊戲結束時，主畫面下方會出現 **[✔ 計分]** 和 **[🎮 試玩不計分]**：按「計分」才會把這一場的分數累計到每位玩家身上；按「試玩不計分」，或沒選就開始下一場／回大廳，這一場都不算。大廳的 **[🏆 結算排名]** 按下去會列出累計排名表（含各遊戲得分明細，可「重新開始賽季」清空）。累計分數存在瀏覽器裡，玩家用同一支手機重連還是同一個人；手機右上角會顯示「累計 N 分・第 K 名」，大廳玩家列表也會顯示。

**公平的算法**：
- **名次分**：每個遊戲滿分都是 100——第 1 名 100、最後一名 0、中間平均分配（人數 n：`100 × (n − 名次) ÷ (n − 1)`；並列名次平分）。所以不論幾人玩、玩哪個遊戲，一場的分量都一樣。只有 1 人上場不計分。
- **表現加分**（各遊戲最多 +20）。
- **AI 玩家**算在名次裡（讓排名算得出來），但**不進累計排名**。
- 累計排名依總分；同分比「拿過幾次第 1」，再比表現加分總和，還一樣就並列。

| 遊戲 | 名次依據 | 表現加分 |
|---|---|---|
| 🏃 跑步 | 全部組別依抵達時間統一排名 | 第一個到終點 +5；技能成功每次 +2（上限 +6） |
| ⚽ 足球 | 隊伍分：贏的隊每人 100、平手 50、輸 0 | 個人進球每球 +5（上限 +20） |
| 🌀 陀螺大戰 | 最終名次（最後留下的人在前，其餘依淘汰順序） | 擊殺 ×2（上限 +20） |
| ❓ 猜猜他是誰 | 題目總分名次（同分並列） | 答對題數 ×4（上限 +20） |

**足球分隊**：已有累計分數時，依分數「蛇形」分隊（高分者：紅、藍、藍、紅、紅、藍…），讓兩隊實力接近；還沒有分數就依加入順序輪流分。

### 猜猜他是誰的音檔

## 陀螺大戰：橢圓平台、上方擋板、滑動衝撞

- **橫的橢圓平台**：橫向半徑 500（`ARENA_A`）、縱向半徑 300（`ARENA_R`），左右加大；第 2 回合縮圈時整個橢圓等比縮小。碗的拉力橫向、縱向邊緣一樣大。
- **上方擋板**：橢圓上方 120° 的弧（正上方 ±60°，`WALL_FROM/WALL_TO`）有擋板：圓盤不會從這一段掉出去，會被彈回來（`WALL_E`）。其餘的邊緣照樣會掉出去。
- **擋板區衝撞**：貼近擋板（離中心 `WALL_ZONE` 以外）、**往下**衝撞時，衝力 ×`WALL_RAM_MUL`（1.9）、撞到人的力道 ×`WALL_RAM_POWER`（3.2），被撞到的人速度上限也放寬，所以可以直接把人打出平台。畫面上擋板區有淡黃色底，往下衝時畫面會震一下。
- **衝撞改成「按住 → 滑動方向 → 放開」**：手機上按住「衝撞」鈕，往想衝的方向滑（會有白色箭頭），放開才衝出去；**單純點一下不會觸發**（也要滑過一定距離才算）。搖桿模式（右側按鈕）與傾斜模式（傾斜圈下方的鈕）都一樣。冷卻照舊，放開衝出去的那一刻開始算。
- AI 的衝撞也會帶方向；AI 的邊緣判斷改用橢圓座標。

# 陷阱跑酷（類似「超級雞馬」）

最多 6 人、固定 8 回合。程式在 `public/games/trap.js`，手機操作在 `public/controller.js`（`trapPad`），AI 在 `public/ai.js`（`trapTick`）。

## 每回合三段

1. **挑道具**（12 秒）：派對箱裡有「人數 + 2」個隨機道具（最多 8 個），大家在手機上搶，先搶先贏；時間到沒搶的人從剩下的隨機分一個。
2. **放道具**（18 秒）：手機上用方向鍵移動游標（按住會連續移動）、「旋轉」、「放下」。主畫面上每個人的游標是自己衣服顏色，放不下的位置變紅。起點、終點附近（淡白色區域）不能放。全部人放好就提早開始。時間到沒放的道具作廢。道具會一直留在關卡上，越來越難。
3. **衝刺**（不限時）：所有人同時從起點出發，碰到旗子就算到終點。全部人都到終點或死掉才結束；卡關時玩家可以在手機上按「放棄」，主持人也可以按畫面左上角的「結束這回合」。

## 計分（每回合）

| 情況 | 得分 |
|---|---|
| 到終點 | +10 |
| 第一個到 | +5 |
| 只有你到（2 人以上） | +5 |
| 你放的陷阱（尖刺、鋸片、十字弓的箭）殺了別人 | 每個 +3 |
| 全部人都到（太簡單）或沒人到（太難） | 這回合沒人得分 |

8 回合後依總分排名，接到大廳的累計積分（表現加分 = 陷阱擊殺數 ×2）。

## 操作手感

- 左右移動、按住「跳」跳得比較高（提早放開跳比較低）。
- 離開平台的一瞬間（0.1 秒）還能跳、落地前一點按跳也算。
- 貼著牆往牆推會慢慢滑下來，這時按跳可以蹬牆跳。
- 玩家之間互相穿過，不會互撞。

## 道具

| 道具 | 效果 |
|---|---|
| 📦 木箱（1×1） | 實心，可以踩 |
| 🪵 木板（1×3） | 實心，可以踩，可旋轉成直的牆 |
| 🔺 尖刺 | 碰到就死（可旋轉朝不同方向） |
| ⚙️ 鋸片 | 碰到就死，會轉 |
| 🏹 十字弓 | 實心，每 2 秒往它面向的方向射一支箭，箭碰到就死 |
| 🟢 彈簧 | 實心，碰到朝外的那一面會被彈飛（朝上：彈很高；朝側邊：往旁邊彈） |
| 💣 炸彈 | 放下時炸掉周圍 3×3 格的所有道具（地形炸不掉），本身不會留下 |
| 🧊 冰塊（1×2） | 實心，站在上面很滑 |

## 地圖

三張隨機：斷崖（浮島跳躍）、階梯（一階一階往上再往下）、大坑（平地中間一個大坑和兩道矮牆）。

## 數值（`trap.js` 最上方）

`RUN`、`JUMP_V`、`GRAV`（跑速、跳躍力、重力）、`COYOTE`、`JUMP_BUF`、`WALL_SLIDE`、`WJ_*`（蹬牆跳）、`SPRING_V`、`BOW_PERIOD`、`PICK_MS`、`PLACE_MS`、`PTS_*`（計分）。
